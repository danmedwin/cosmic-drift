# Cosmic Drift on iOS (Capacitor)

The App Store build is the same two web pages (`index.html`, `workshop.html`)
loaded from the app bundle inside a WKWebView, plus a thin native layer:
haptics, the share sheet, durable storage, Game Center and the launch screen.
Nothing is fetched from the network.

## Layout

| Path | What it is |
|---|---|
| `capacitor.config.json` | App id `com.medwin.cosmicdrift`, `webDir: www`, iOS options, plugin options |
| `www/` | **Generated.** The web bundle Capacitor copies into the app. Not committed. |
| `www-sync.js` | Fills `www/` from the built pages, `vendor/`, the music, icons, `privacy.html` |
| `ios/App/App.xcodeproj` | The Xcode project (Swift Package Manager, no CocoaPods) |
| `ios/App/App/CDViewController.swift` | Hosts the web view inside the safe area, registers local plugins (created by `SceneDelegate.swift`, not the storyboard) |
| `ios/App/App/GameCenterPlugin.swift` | Game Center leaderboards (see `GAMECENTER.md`) |
| `ios/App/App/WorkshopPassPlugin.swift` | Workshop Pass in-app purchase, StoreKit 2 (see `IAP.md`) |
| `ios/App/App/Products.storekit` | StoreKit configuration for testing the purchase in the Simulator |
| `ios/App/App.xcodeproj/xcshareddata/xcschemes/App.xcscheme` | Shared scheme; its Run action attaches `Products.storekit` |
| `ios/App/App/App.entitlements` | Game Center entitlement |
| `ios/App/App/Assets.xcassets` | App icon + launch image, generated by `npm run ios:assets` from `assets/` |
| `assets/` | 1024px icon and 2732px splash sources for `@capacitor/assets` |
| `vendor/capacitor.js` | Capacitor JS runtime (copied from `@capacitor/core`), loaded by both pages |

## Build and run

```bash
npm install            # once
npm run ios:sync       # build both pages -> www/ -> copy into ios/App/App/public
npm run ios:open       # opens the Xcode project; pick a simulator or device, press Run
```

`npm run ios:sync` is the whole loop after any `.jsx`, `build.js` or asset edit.
Without Xcode's UI:

```bash
xcodebuild -project ios/App/App.xcodeproj -scheme App -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

First build resolves `capacitor-swift-pm` from GitHub (needs network once).

To run on a device or upload to TestFlight: Xcode → App target → Signing &
Capabilities → pick your team. Automatic signing creates the App ID and adds
the Game Center capability from the entitlements file.

Icons and splash: edit `assets/icon-only.png` (1024×1024) and
`assets/splash.png` / `splash-dark.png` (2732×2732, keep the art inside the
centre ~1200px), then `npm run ios:assets`.

## What the native layer does

All of it is behind `window.CDNative` (defined in `build.js`); in a browser
`CDNative.isNative` is false and every call is a no-op, so the web build is
unchanged.

- **Haptics:** light tap on fire, medium tap per destroyed block (rate-limited
  to one per 40 ms so chain reactions buzz rather than stutter), success
  notification on level clear and new high score.
- **Share:** every Workshop export overlay (level, set, design, effect, UFO,
  ship, plasma, and the Export All variants) gets a **Share** button next to
  Copy that opens the iOS share sheet with the JSON as text.
- **Durable storage:** the `window.storage` shim still writes `cd_*` keys to
  localStorage (shared by both pages) but also mirrors every write and delete
  into Capacitor Preferences (UserDefaults). On each page load any `cd_*` key
  missing from localStorage is restored from Preferences before the app reads
  it, so WKWebView evicting website data does not lose progress or designs.
  Keys that exist only in localStorage (older data, or seeds written by the
  Workshop iframe on the game splash, which has no native bridge) are uploaded
  on every load, and storage events from that iframe are mirrored live.
- **Game Center:** scores go to the leaderboard for the current mode and
  difficulty whenever a best score is saved; the splash gets a LEADERBOARDS
  button. IDs and App Store Connect steps: `GAMECENTER.md`.
- **Safe area:** the web view is pinned to the safe-area layout guide inside a
  navy container, so the title bar, HUD and Workshop top bars never sit under
  the Dynamic Island or the home indicator. The status bar uses light text.
- **Orientation:** portrait only. iPad is portrait + upside-down with
  `UIRequiresFullScreen` (required when an iPad app does not support all
  orientations; it also opts out of Split View).
- **Launch screen:** the storyboard shows the splash image; the page hides it
  with a 250 ms fade once React has rendered (`CDNative.ready()`).
- **Install banner:** the "Make this an app" prompt is suppressed in the app.
- **Audio:** music starts on the first PLAY tap (an AudioContext needs a user
  gesture, same as the web). When the page is hidden (app switcher, lock
  screen) the loop is silenced and resumed on return only if it was playing.
  WKWebView's web audio uses the *ambient* session, so the ring/silent switch
  silences the game like most casual games; change the AVAudioSession category
  in `AppDelegate.swift` if Dan prefers music to ignore the switch.

- **Workshop Pass:** the one-time purchase that unlocks the Workshop, plus
  the free-tier gates in both pages. `IAP.md` has the product details, the
  Simulator test loop (run from Xcode so the StoreKit configuration applies)
  and the App Store Connect steps.

## Gotchas

- Both pages are served from `capacitor://localhost`, so relative links
  (`workshop.html`, `index.html?play=…`) and shared localStorage work exactly
  as on the website.
- `ios/App/App/public` and `ios/App/App/capacitor.config.json` are generated
  by `cap sync` and git-ignored; `www/` too. Commit the `.jsx`, `build.js`,
  the built `.html` files and everything under `ios/` that is not ignored.
- After upgrading `@capacitor/core`, re-copy `dist/capacitor.js` to
  `vendor/capacitor.js`.
- The repo lives in an iCloud Drive folder. iCloud occasionally resurrects a
  just-deleted file as `name 2.ext`; `www-sync.js` sweeps those out of `www/`
  so they never ship. Point `xcodebuild -derivedDataPath` outside the
  Documents folder (or leave it at the default) or CodeSign fails on Finder
  metadata.
